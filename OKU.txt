TETHER  v2.16.1
==============
Premiere Pro paneli: videodaki bir nesneyi (yuz, kafa, top...) kare kare izler ve
hedef klibin Position / Scale / Rotation animasyonuna cevirir (After Effects tarzi takip).

ENGLISH (short)
  Tether tracks an object (face, head, ball...) frame by frame in a video and turns it into Position / Scale / Rotation animation on a target clip in Premiere Pro (After Effects-style tracking).
  Install: Windows - double-click kur.bat; Mac - run kur.command. Then restart Premiere: Window > Extensions > Tether.
  (kur.bat downloads ffmpeg once, ~170 MB, with a progress bar; it needs internet.)
  Use: select the clip, go to the frame where the object is visible, press "Grab frame", draw a box over the object, press "Track".
  Then select the target clip(s), press "Get selected clips", pick a mode and press "Apply".
  Language: Settings > General > "Dil / Language" (Turkish / English). New installs follow the system language.
  What's new in v2.16.1: "Automatic" method switches to "Cursor / small object" by itself for tiny objects (mouse cursor) when point tracking can't hold on; camera follow now works in vertical 9:16 sequences (zoom limit rises automatically, no black bars); shorter, plainer names in the panel; simpler Reframe zoom card; clearer preview (draggable blue cross with live values); usage hints for Stabilize and tracking model; drag number fields left/right like Premiere (or click and type); "Back to previous tracking" button after re-tracking.
  What's new in v2.16.0: English interface; tracking continues after a scene cut when you re-track from there (small objects too);
  "Apply to" (Motion / Transform) moved into the Mode card; clearer hints (why "Track" is disabled); confirmation before "Reset animation";
  "Copy log" button; ffmpeg download progress bar in kur.bat; the old Object Mask / Premiere mask code was removed (the own tracking engine is the only source now).
  Known limits: very fast or occluded small objects can drift; perspective / planar tracking is not supported; very fast targets can lag slightly.

KURULUM
  Windows : kur.bat dosyasina cift tikla
  Mac     : kur.command dosyasini calistir
  Sonra Premiere'i kapatip ac:  Window > Extensions > Tether
  Eski "Mask Takip" paneli varsa kurulum onu otomatik kaldirir. Kaldirmak icin: sil.bat

KULLANIM (Takip sekmesi)
  1) Takip edilecek klibi timeline'da sec, oynatma cubugunu nesnenin gorundugu kareye koy  ->  "Kare al"  ->  nesnenin ustune kutu ciz  ->  "Takip et"
  2) Takibin uygulanacagi klip(ler)i sec  ->  "Seçili klipleri al"
  3) Modu sec  ->  "Uygula"
  Onizleme ustte: ayar degistikce canli guncellenir; kare kaydirici, oynat, ve onizlemede
  surukleyerek hedef konumu / kadraj konumu ayarlanir. Alttaki tutacla boyutu degistir
  (cift tikla: kucult/buyut).
